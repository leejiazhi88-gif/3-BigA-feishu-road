# 2026-10-29 全部表：盈利预测口径修正

对现有 WYWO67 工作表重新核算 2026—2028 年利润、季度利润、预测 PE、同比和年度变化率。信息截止日仍为 2026-10-29，取数时间为 2026-10-30。行情、股票名单、笔记、行业底色、主营构成和锁定比较列保持不变。

## 规则

- 每次重新请求 report_rc；按机构、预测年度保留最新一条。归母净利润统一为亿元。
- 90 个自然日内的报告才参与当前机构中位数。优先最新财报披露后报告，缺少时采用近 90 日报告并标记“财报后未更新”。同机构同日预测冲突不按输入顺序静默选取。
- 对缺失、过期、全年低于累计实际或与实际运行基准偏差超过 50% 的公司，补查东方财富公开券商研报。仅提取正文明确标注年度、归母口径和单位的数字，不从 EPS、营收或搜索摘要推断利润。
- 缺少有效机构预测时，2026 年采用已披露实际加剩余季度估算。非周期行业在 2024/2025 两年季节性均满足各季占比 5%—60%、跨年各季权重差不超过 15 个百分点时，按稳定季节性外推；其他情况按最近披露单季利润持平推算剩余季度。
- 未来年度模型以此前年度估算为基数，参考同份研报中相邻两年的增长路径。研报最长追溯 365 天，各机构仅保留最新配对，再保留距离最新可得配对 90 天内的记录；仅正利润且年利润比在 0.5—2 范围内采用该路径。否则按前一年持平。所有这类结果均标为模型估算，历史路径不是当前机构共识。
- 新上市公司若只有累计财报而缺失单季拆分，按累计余额分摊缺失季度，单元格明确标记“累计拆分估算”，不冒充已披露单季实际。
- 按显示的一位小数校验四季度之和等于全年；舍入尾差仅放入最后一个预测季度，不调整已披露单季显示数。全部季度已披露时，全年显示为各单季显示值之和，可能与累计值直接舍入差 0.1 亿元。
- 年度变化率使用（新值－旧值）/绝对值（旧值），避免亏损收窄被标红。基期为零或缺失时不伪造百分比。年度变化文字按变动的最近年度判色，S/T/U 按对应年度正绿、负红、零黑。
- PE 在亏损或利润为零时显示“亏损”或“不适用”。同比基期为零时明确标记，不制造无穷大。

## 审计文件

- `summary.json`：覆盖数量、来源分类和变动数量。
- `audit.json`：每家公司逐年使用的机构、日期、金额、模型假设、排除统计及每类排除的机构最新记录。
- `annual_changes.csv`：年度利润旧值、新值、变化率，便于直接查看。
- `changes.json`：年度及季度变动明细。
- `external_checks.json`：公开研报补查结果、正文摘录和来源链接。
- `fetch_log.json`：主数据源重新取数记录。
- `verification.json`：在线数据回读与保护项校验。
- `format_verification.json`：原生导出文件的 16 个工作表、281,512 个单元格对比及 4,620 项字体颜色规则检查。底色、数字格式和未编辑单元格样式一致；飞书两次导出的行高、列宽采用了不同的全局单位换算（未编辑工作表也同步出现），单独记录换算比例，不将其视为在线尺寸修改。

默认来源为 Tushare，在线表仅对非 Tushare 来源额外标记。模型估算与机构预测明确区分；“财报后未更新”、大幅偏离与分歧提示不因算术对账成功而隐藏。未重新计算股息率派息政策，本次范围为年度与季度盈利预测及上述关联估值字段。
